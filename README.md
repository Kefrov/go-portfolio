## Makefile

- `dev` → Run the app with live reload using Air (requires Air installed).

- `fmt` → Format all Go files in the project.

- `tidy` → Clean up and update Go module dependencies.

- `build` → Build the executable to `bin/go-portfolio`.

- `clean` → Remove all files inside the `bin` directory (Windows only).

> **Note:** This is my first web project, so the focus is mainly on functionality rather than UI design.
